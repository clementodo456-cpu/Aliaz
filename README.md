# 📸 Photo Collage Creator Telegram Bot

A Telegram bot (`@aliazsteelbot`) built with Python 3.11+, Pillow, and `python-telegram-bot` to create customized photo collages directly inside Telegram.

## Features
- Upload 2 to 12 images.
- Multiple collage layouts (Grid 2x2, Grid 3x3, 1 Large + 2 Small, Strips, Auto).
- Color background customization (white, black, gray, custom HEX).
- Custom border spacing and image fitting modes (crop, fit, stretch).
- Auto EXIF rotation correction and high-performance downscaling.
- Render Web Service ready with HTTP `/health` check and webhook support.
